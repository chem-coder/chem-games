# Steam Concept — parked (2026-10-17)

Game-design ideas from the October 2026 discussions (friend + Gemini), kept so they are not lost while the course is built first. Source transcript: `idea-box/steam-and-edtech-plan-gemini-2026-10.txt`. Working title used in the transcript: **"Architects of Matter."** Genre reference points: Turing Complete, SpaceChem, Opus Magnum, World of Goo.

## Identity (the three questions)

- **Why:** the player masters chemistry at the atomic level to take on real problems — climate, disease, materials, energy. Target feeling: *I now possess skills to make something real, and I want to learn more.* ("Epic meaning.")
- **What:** explore a non-linear skills map; max out levels to uncover hidden tiles; collect apparatus parts; assemble instruments in a lab and run real procedures.
- **How:** one core mechanic that scales — **interaction of + and − charges** (her spine). Electrons onto a nucleus → bonds → polarity → dissolution → proton transfer → electron transfer → partial charges in DNA. Her first storyboard (a plus and a minus) is the opening.

## Mechanics catalogue

- **Fog of war** on the map; links light up when a path opens.
- **Mastery indicators** as chemistry objects (flask filling, crystal growing), not percentages.
- **Hidden tiles (secret rooms):** six, fixed positions for all players (so discoveries can be shared), revealed only by 100% mastery of neighboring tiles; a counter "0 / 6" and a flicker on adjacent links as teaser; the sixth on the final tier.
- **Set collecting — assemble a distillation apparatus:** five hidden tiles each hold one part (Wurtz/round-bottom flask, thermometer, Liebig condenser, adapter, Erlenmeyer receiver); the lab shows the empty stand with ghost outlines; the sixth tile upgrades it (vacuum pump / column). Distillation is locked until complete.
- **Other collectible instruments:** Kipp apparatus (gas chemistry), Soxhlet extractor (natural-product extraction), Büchner funnel + vacuum flask (fast filtration), electrolysis cell (plating, metallurgy), crucible + oven + balance (gravimetry). Titration as a timing game (close the burette at the color change).
- **Fail states:** wrong answers raise "instability" (temperature); three misses = humorous explosion, replay the level.
- **Random events:** timed anomalies / requests from scientists for double points.
- **Global quests:** four world problems on the map (warming, disease, energy, oceans), each attackable only after specific branches.
- **Reality bridge:** after a block, a card linking the skill to a real present-day use and a real young scientist.
- **"Mighty Goo" idea:** a programmable nanomaterial as the central object the player transforms with each learned procedure (CO₂ → bioplastic, distillation → hydrogel, electrolysis → supercapacitor).

## Steam-specific reasoning kept

- Steam provides payments, cloud saves, leaderboards, store page — the reason it was attractive; cost is 30%.
- Pricing shape if it ever ships: low base price for fundamentals, exam-prep content as paid DLC.
- Course-first plan: the course validates which modules players enjoy and funds the game; the game reuses the modules.
